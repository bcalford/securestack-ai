# SecureStack AI v0.8.0-beta release notes

SecureStack AI v0.8.0-beta is a stabilization-focused beta release for the local-first defensive security review workflow. It prepares the project for broader evaluation without adding major new product features or overstating production readiness.

## Focus areas

- Stabilization of the existing guided review, results, exports, rule catalog, history, and comparison workflows.
- Clean-machine validation for Java 21, Maven, Node.js 20+, npm, Docker Compose, backend tests, frontend lint/tests/build, guardrail scripts, and CI-aligned local checks.
- Accessibility and responsive polish across the main review and reporting surfaces, including keyboard navigation, visible focus states, semantic controls, and readable layouts.
- Edge-case fixes discovered during beta hardening while preserving existing backend behavior, API contracts, deterministic rules, and local-first safety boundaries.
- Demo walkthrough polish so reviewers can evaluate the sample review flow, findings, review artifacts, exports, and limitations consistently.
- Dependency and build hygiene documentation that favors locked installs, Maven validation, conservative audit review, and no broad dependency churn during beta stabilization.
- Documentation consistency across README, roadmap, validation, troubleshooting, release notes, and technical-review materials.

## Scope

This beta does not introduce major new product features. SecureStack AI remains a local/demo-oriented defensive review application: mock AI is the default, uploaded code is not executed, raw file storage is disabled by default, public GitHub import is public-only and unauthenticated, SARIF support is export-only, and the app is not a hosted scanner.

## Validation focus

Before sharing the beta, run duplicate/copy guardrails, secret-safety checks, quick or full local validation, and Docker Compose configuration validation when Docker is available. Use `./scripts/validate-all.sh --quick --skip-docker` for non-Docker quick validation in environments without Docker.
