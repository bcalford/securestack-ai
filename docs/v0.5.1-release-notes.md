# SecureStack AI v0.5.1 release notes

SecureStack AI v0.5.1 is a patch release focused on documentation and release polish after the v0.5 frontend redesign work.

## Highlights

- Standardizes current release references on semantic patch version naming: `v0.5.1`.
- Cleans up documentation around the v0.5 frontend redesign so current-version wording is consistent.
- Refreshes screenshot documentation and README screenshot references for the polished UI walkthrough.
- Captures final UI/documentation polish before the next beta/stabilization phase.
- Keeps validation centered on the local-first defensive review workflow.

## Scope

This patch release does not add backend features, change scan logic, alter API contracts, or introduce new integrations. Mock AI remains the default, uploaded code remains unexecuted, and SARIF support remains export-only.

## Validation focus

Before moving toward the next beta/stabilization milestone, v0.5.1 emphasizes repository hygiene, documentation consistency, screenshot-reference accuracy, duplicate-file guardrails, secret-safety checks, and the existing local validation workflow.
