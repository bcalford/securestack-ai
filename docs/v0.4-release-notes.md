# SecureStack AI v0.4-alpha release notes

SecureStack AI v0.4-alpha is a release-readiness milestone for the local-first defensive security review workflow.

## Highlights

- Hardened public GitHub URL import for unauthenticated public repositories with local-only analysis and no token handling.
- Expanded deterministic rule coverage across secrets, authentication/session risks, API security, dependency scripts, Dockerfiles, cloud/IaC configuration, logging/data exposure, and input-validation patterns.
- Improved rule catalog metadata, including stable IDs, remediation guidance, secure examples, false-positive notes, review-depth behavior, and control mappings.
- Hardened SARIF 2.1.0 export with deterministic output and no raw uploaded file contents.
- Added JSON report export and a ZIP export bundle for completed reviews.
- Added backend-generated threat model, defensive risk-path grouping, fix plan, and security review checklist artifacts.
- Added regression scan comparison for completed local scans.
- Polished local validation scripts, duplicate/copy artifact checks, secret-safety guardrails, Make targets, Docker Compose config validation, and CI coverage.

## Known limitations

- No authentication or authorization.
- No public deployment or hosted scanner.
- No private GitHub repository support.
- No OAuth flow, GitHub App, or token-based GitHub import.
- No GitHub code scanning upload or automation.
- No OpenAI provider.
- No Semgrep execution or integration.
- SARIF support is export-only; SARIF import/ingestion is not implemented.
- No multi-user production storage.
- No production AWS deployment automation.

## Validation focus

Use `./scripts/validate-all.sh`, `./scripts/check-duplicates.sh`, `./scripts/check-secrets.sh`, and Docker Compose config checks to validate the release locally. Mock AI remains the default path for repeatable validation.
